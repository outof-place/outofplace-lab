# outofplace lab

Live examples for the posts on [outofplace.space](https://www.outofplace.space/blog), served at **https://lab.outofplace.space**.

One demo per post. The code a post shows is taken from the demo, so the code in the post is the code that runs here, and every demo has a Playwright test that checks what the post claims.

- Next.js 16.4.0, React 19.3, `cacheComponents` and `partialPrefetching` on (see `next.config.ts`). No other global flags: a demo that needs one does not belong in this app.
- Vercel project `outofplace-lab` (team OUTOFPLACE). A push to `main` deploys production.

## Rules for every demo

- No secrets, no paid API calls, no user data. AI demos show recorded runs, never live calls.
- The files a post shows are listed in `demos.json` and contain only demo code. Lab chrome (title bar, links, noindex) lives in the demo's `layout.tsx`, which a post never shows.
- The test asserts the post's claims, one test per claim, and fails when a claim stops being true.

## A demo

```
app/demos/<slug>/
  layout.tsx      lab chrome, generated by `lab new`; leave it alone
  page.tsx        the demo route: https://lab.outofplace.space/demos/<slug>
  *.tsx, *.ts     more demo files, if the demo needs them
  README.md       what it shows, the Next.js version, how to run it
  demo.spec.ts    the Playwright test
```

Demo pages send `noindex, follow` (as `<meta name="robots">` and `X-Robots-Tag`) and link to their post, so the post is the page that ranks. The index page lists every demo and can be indexed.

Every response allows framing only by `https://www.outofplace.space` and a local dev server of the site: `Content-Security-Policy: frame-ancestors https://www.outofplace.space http://localhost:* http://127.0.0.1:*`. Preview deployments of the site cannot frame the lab.

## demos.json

```json
{
  "version": 1,
  "demos": [
    {
      "slug": "use-cache-static-shell",
      "title": "use cache and the static shell",
      "summary": "One sentence for the index.",
      "files": ["app/demos/use-cache-static-shell/page.tsx", "app/demos/use-cache-static-shell/stamps.tsx"],
      "test": "app/demos/use-cache-static-shell/demo.spec.ts",
      "next": "16.4.0",
      "post": null,
      "created": "2026-10-14",
      "updated": "2026-10-14"
    }
  ]
}
```

| Field | Meaning |
| --- | --- |
| `slug` | Folder and URL name: lowercase words joined by single hyphens, at most 60 characters. Permanent once a post links to it. |
| `title`, `summary` | Shown on the demo page and the index. |
| `files` | Repo-relative paths a post may show, in display order. All inside `app/demos/<slug>/`; never `layout.tsx`, `README.md` or the spec. |
| `test` | Always `app/demos/<slug>/demo.spec.ts`. |
| `next` | The Next.js version the demo was last verified on. `lab update` sets it to the installed one. |
| `post` | The post's URL under `https://www.outofplace.space/`, or `null` until it exists (the demo then links to the blog). |
| `created`, `updated` | `YYYY-MM-DD`, Europe/Warsaw. |

`lab check` holds the file to these rules and runs before every build, so a broken manifest never deploys.

## Contract

Frozen on 2026-10-14. Commands and fields may be added; existing ones do not change meaning.

```sh
node scripts/lab.mjs <command> [args]     # pnpm lab <command> works too, but pnpm adds its own output
```

- **stdout** is exactly one JSON document: `{ "ok": true, "command": "<name>", ... }`, or on failure `{ "ok": false, "command": "<name>", ..., "error": { "code": "<reason>", "message": "<text>" } }`.
- **stderr** carries progress and the output of `next build` and Playwright.
- **Exit codes:**

| Code | Meaning | Examples (`error.code`) |
| --- | --- | --- |
| 0 | Done, and what was checked is true. | |
| 1 | What was checked is not true. | `tests-failed`, `no-tests`, `manifest-problems`, `dirty`, `timeout` |
| 2 | The call was wrong. Fix the arguments, do not retry. | `unknown-command`, `bad-args`, `bad-slug`, `unknown-slug`, `exists`, `bad-post`, `bad-url`, `out-taken` |
| 3 | The environment broke. Retrying may help. | `build-failed`, `no-build`, `no-report`, `git-failed`, `next-missing`, `internal` |

On this Mac, run `test` (it builds) through `claude-acc run -- node scripts/lab.mjs test ...`.

### `new <slug> --title <title> [--summary <text>] [--post <url>]`

Creates `app/demos/<slug>/` from `templates/demo/` and appends the entry to `demos.json` (`files` starts as `[page.tsx]`, dates are today, `next` is the installed version).

The new `page.tsx`, `demo.spec.ts` and `README.md` carry a `lab:template` line, and `lab check` (so the build) fails until each is written and the line removed.

```json
{ "ok": true, "command": "new",
  "demo": { "slug": "...", "...": "every demos.json field", "url": "https://lab.outofplace.space/demos/<slug>", "dir": "app/demos/<slug>" },
  "created": ["app/demos/<slug>/README.md", "app/demos/<slug>/demo.spec.ts", "app/demos/<slug>/layout.tsx", "app/demos/<slug>/page.tsx"],
  "todo": "..." }
```

### `update <slug> [--title <title>] [--summary <text>] [--post <url>|none]`

Run it after changing a demo or upgrading Next.js: sets `updated` to today and `next` to the installed version, rewrites the README's `Next.js version:` line, and applies the given fields (`--post none` clears the link). Returns `{ "demo": {...} }`.

To add a shown file, edit `files` in `demos.json` directly; `lab check` verifies it.

### `check`

Validates `demos.json` against `app/demos/`: required files, shown files inside the demo folder and present, the README's version line, leftover template lines, folders without an entry. Exit 1 on any problem.

```json
{ "ok": true, "command": "check",
  "demos": [{ "...": "every demos.json field", "url": "...", "dir": "..." }],
  "problems": [{ "slug": "x", "message": "..." }],
  "warnings": [{ "slug": "x", "message": "verified on Next.js 16.4.0, the lab runs 16.5.0; ..." }] }
```

### `test [slug...] [--url <base>] [--no-build]`

Runs Playwright.

- **No `--url`:** runs `next build` (skip with `--no-build` when `.next/` is fresh), serves it with `next start` on a free port, tests, and stops the server.
- **With `--url`:** tests that deployment, for example `--url https://lab.outofplace.space`. Remote runs retry a failed test once; a pass on retry counts as `flaky`.
- **Scope:** with slugs, only those demos' specs run. Without slugs, every demo runs plus the lab-wide tests in `tests/` (headers, framing, noindex, index, `version.json`).

```json
{ "ok": true, "command": "test", "target": "https://lab.outofplace.space",
  "demos": ["use-cache-static-shell"], "specs": ["app/demos/use-cache-static-shell/demo.spec.ts"],
  "stats": { "passed": 4, "failed": 0, "flaky": 0, "skipped": 0 },
  "failures": [{ "file": "...", "title": "...", "error": "..." }],
  "errors": [], "durationMs": 5120, "report": "/abs/path/test-results/lab-report.json" }
```

### `snapshot <slug> --out <dir>`

Writes `<dir>/snapshot.json`: the demo's shown files, read from git at `HEAD`, and that commit's SHA.

- **Refuses (exit 1, `dirty`)** when `demos.json` or a shown file differs from `HEAD` or is untracked, because the SHA would then not describe the files.
- **Refuses (exit 2, `out-taken`)** to overwrite a `snapshot.json` that is not a snapshot of the same demo.
- **No timestamp:** the same commit always writes the same bytes.

stdout:

```json
{ "ok": true, "command": "snapshot", "slug": "use-cache-static-shell",
  "commit": "<40 hex>", "pushed": true, "out": "/abs/dir/snapshot.json",
  "files": [{ "name": "page.tsx", "path": "app/demos/use-cache-static-shell/page.tsx", "lang": "tsx", "bytes": 1234, "sha256": "...", "url": "https://github.com/outof-place/outofplace-lab/blob/<commit>/app/demos/use-cache-static-shell/page.tsx" }] }
```

`pushed` says whether `HEAD` is already in the local `origin/main`; publish a post only from a pushed and deployed commit.

`snapshot.json` (schema 1), the file a site build reads:

```json
{
  "schema": 1,
  "slug": "use-cache-static-shell",
  "title": "use cache and the static shell",
  "commit": "<40 hex>",
  "next": "16.4.0",
  "updated": "2026-10-14",
  "demoUrl": "https://lab.outofplace.space/demos/use-cache-static-shell",
  "sourceUrl": "https://github.com/outof-place/outofplace-lab/tree/<commit>/app/demos/use-cache-static-shell",
  "files": [
    { "name": "page.tsx", "path": "app/demos/use-cache-static-shell/page.tsx", "lang": "tsx",
      "bytes": 1234, "sha256": "...", "url": "https://github.com/.../blob/<commit>/...", "content": "the file, verbatim" }
  ]
}
```

The code lives inside the JSON on purpose: loose `.tsx` copies in the site repo would be picked up by its TypeScript, linter and formatter.

### `wait --url <base> --commit <sha> [--timeout <s>] [--interval <s>]`

Polls `<base>/version.json` until it serves `<sha>` (7 to 40 hex characters, prefix match). Defaults: timeout 900 s, interval 10 s. Exit 1 (`timeout`) if it never does.

```json
{ "ok": true, "command": "wait", "url": "https://lab.outofplace.space", "commit": "abc1234", "served": "<40 hex>", "attempts": 7, "waitedMs": 61000 }
```

`GET /version.json` returns `{ "commit": "<40 hex>" }` for the deployment, prerendered at build time.

## The autopilot's path for a tutorial

```sh
node scripts/lab.mjs new <slug> --title "..." --summary "..." --post https://www.outofplace.space/blog/<post-slug>
# write page.tsx (and more files), demo.spec.ts, README.md; list shown files in demos.json
node scripts/lab.mjs check
claude-acc run -- node scripts/lab.mjs test            # every demo plus the lab-wide tests, local build
git add -A && git commit -m "feat(demos): <slug>" && git push origin main
node scripts/lab.mjs wait --url https://lab.outofplace.space --commit "$(git rev-parse HEAD)"
node scripts/lab.mjs test <slug> --url https://lab.outofplace.space
node scripts/lab.mjs snapshot <slug> --out <site>/content/lab/<slug>
```

Any non-zero exit stops the post: a tutorial never ships with a broken example. For a release post that changes an existing demo, use `update` instead of `new`.

## Working on the lab

```sh
pnpm install
pnpm build && pnpm start      # production server on :3000
pnpm test                     # the CLI's own tests (node:test, throwaway git repos)
pnpm test:e2e                 # = node scripts/lab.mjs test
pnpm typecheck
```

A local run needs Playwright's Chromium (`pnpm exec playwright install chromium`). The framing tests start Chromium with Local Network Access checks off, since they frame a localhost lab from a page served as `https://www.outofplace.space`.
